# Autos Colombia — Código fuente

Prototipo académico para la gestión de un parqueadero.

## Ejecutar
1. Extraiga el archivo ZIP.
2. Abra `index.html` con un navegador actualizado (Chrome, Edge o Firefox).
3. Use las opciones Registrar entrada, Consultar vehículos, Registrar salida y Novedades.

## Funciones incluidas
- Registro de entrada de vehículos.
- Consulta y filtrado de vehículos.
- Registro de salida.
- Registro de novedades.
- Indicadores de vehículos dentro, entradas y novedades.

## Almacenamiento y limitaciones
Este prototipo guarda los registros en el almacenamiento local del navegador (`localStorage`). Los datos quedan en ese navegador y equipo; no hay servidor ni base de datos central. Es una versión demostrativa para la actividad académica, no un sistema de producción. No ingrese datos personales reales.

## Publicación en GitHub
Cree un repositorio nuevo llamado `autos-colombia-parqueadero` y cargue `index.html` y `README.md`. Si activa GitHub Pages desde Settings > Pages, puede publicar el prototipo como sitio estático.
